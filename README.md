## 🚀 Live Demo & Deployment

This application is built with **React**, **Vite**, and **Tailwind CSS**, optimized for instant builds and 1-click deployment on **Vercel** and **GitHub Pages**.

### Deploying to Vercel

The repository includes both root `vercel.json` and `frontend/vercel.json` configurations with preconfigured build commands and SPA rewrites.

1. **Option A (Root Directory default `./`):**
   - Import this repository into Vercel.
   - Vercel automatically detects the root `vercel.json` and runs `npm run --prefix frontend build`, serving `frontend/build`.

2. **Option B (Root Directory set to `frontend`):**
   - In Vercel Project Settings > General > **Root Directory**, set to `frontend`.
   - Vercel will run `npm run build` using Vite and serve the `build` output.

## 🛠️ Local Development

### Prerequisites
- Node.js >= 18 (Node 20 recommended)
- npm >= 9

### Quick Start
```bash
# Clone the repository
git clone https://github.com/tayal1989/vishal-qa-portfolio.git
cd vishal-qa-portfolio

# Install frontend dependencies
cd frontend
npm install

# Start local dev server
npm run dev
# The app will open at http://localhost:3000
```

### Production Build
```bash
# From repository root
npm run build

# Or from inside frontend/
cd frontend
npm run build
```
